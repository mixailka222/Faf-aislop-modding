# Some features

Проект мода для Supreme Commander: Forged Alliance Forever.

Мод предоставляет три независимые функции, каждая включается отдельной галочкой в
настройках ReUI:

- выделение инженеров, командиров и SACU через Shift+Alt;
- приказ Move через Ctrl+ПКМ;
- установка приоритета атаки по типу юнита через СКМ.

Мод требует ReUI. При отсутствии ReUI функции отключаются, а в лог записывается
предупреждение.

Настройки находятся в ReUI Options, страница «Some features»: три галочки с
английскими подписями. Изменение галочки действует сразу, перезапуск игры не нужен.

Shift+Alt не очищает выделение, если подходящих юнитов нет: в этом случае остаётся
прежнее выделение.

## Ctrl+ПКМ

Пока зажата клавиша Ctrl, движок не берёт юнит под курсором для командного клика:
ПКМ по вражескому юниту становится Move в точку под курсором, а не Attack по этому
юниту. Для этого мод включает встроенный режим игнорирования цели, в котором движок
принимает только Move и Attack Move. Режим включается в тот кадр, когда нажат Ctrl,
то есть до клика: движок читает его во время обработки клика, и переключение внутри
обработчика уже поздно. Игра сама выключает режим при смене курсора, например когда
курсор попадает на вражеский юнит, поэтому мод удерживает режим включённым, пока
Ctrl зажат, и отпускает при отпускании Ctrl.

## СКМ

СКМ по юниту задаёт выделенным юнитам приоритет атаки не по конкретному юниту, а по
его роли. Роль берётся из категорий блюпринта, поэтому приоритет действует на все
фракции и все техуровни: СКМ по истребителю (ASF) задаёт приоритет по истребителям,
СКМ по мобильной ПВО задаёт приоритет по сухопутной ПВО. Точный блюпринт в приоритет
не входит, иначе он перекрыл бы всю роль.

Роли зданий отделены от ролей мобильных юнитов, потому что одни и те же категории
означают разное. СКМ по генератору задаёт приоритет по экономике, которая взрывается:
генераторы, накопители энергии и масс-фабрикаторы, а генераторы Т1 идут ниже, чем
Т2 и Т3. Это не приоритет по «всем структурам»: юниты не будут отвлекаться на стены,
турели и прочие здания. СКМ по масс-экстрактору задаёт приоритет по масс-экстракторам,
СКМ по турели ПВО — по статичной ПВО, СКМ по щиту — по щитам.

Средний клик по активному шаблону постройки не перехватывается: шаблон по-прежнему
вращается.

У FAF нет категорий «истребитель» и «штурмовик», поэтому роль берётся из того, что
есть: перехватчик Т1 считается ПВО, истребитель-бомбардировщик Т2 —
бомбардировщиком, истребитель Т3 — истребителем (`ASF`), штурмовик — самолётом
поддержки наземных войск (`GROUNDATTACK`).

## Игровые сценарии

Сценарии находятся в `tests/game/`: `selection`, `mouse_features` и `options`.
Сценарий мыши использует синтетические события `WorldView` и подмену функций, потому
что стенд `game_test.py` умеет двигать курсор и нажимать клавиши, но не умеет
посылать настоящие нажатия кнопок мыши. Поэтому Ctrl+ПКМ и СКМ дополнительно нужно
проверить вручную в матче.
