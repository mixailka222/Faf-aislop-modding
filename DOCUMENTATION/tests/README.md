# Общие тесты — папка пуста, и это не ошибка

Здесь должны лежать тесты, которые пригодны **любому** UI-моду FAF:
такие, которые запускаются на любом моде без его исходников.

## Почему пусто

Тесты, которые у нас есть, привязаны к конкретным модам и лежат рядом
с ними:

| Тест | Где лежит | Что проверяет |
| --- | --- | --- |
| `test_overflow_rows.py` | `My_mods\overflow\tests\` | `rows.lua`, `sync.lua`, `ui.lua`, `Options.lua` мода Overflow |
| `negative_overflow.py` | `My_mods\overflow\tests\` | ломает мод Overflow намеренно и требует, чтобы тест покраснел |
| `test_watch_unit.py` | `My_mods\reclaim_pause\tests\` | `settings.lua` и `watch.lua` мода ReclaimPause |
| `test_options_unit.py` | `My_mods\reclaim_pause\tests\` | страницу настроек UMT в `options.lua` |
| `test_sync_unit.py` | `My_mods\reclaim_pause\tests\` | формулу расчёта в `sync.lua` мода Overflow |

Проверять `rows.lua` мода Overflow имеет смысл только рядом с ним.
Поэтому тест лежит в папке мода: перенёс мод — перенёс тест, и они не
разъедутся.

## Что здесь появится

Только тест, который **не знает ни об одном конкретном моде**. Например:

* проверка, что мой код не читает несуществующую глобальную переменную
  (это фатально для всего мода, методичка 3.6);
* проверка, что в функции не больше 32 upvalue (3.10);
* проверка, что в ключе настроек нет точек (11.1);
* проверка, что файл мода не использует запрещённые имена.

Часть из этого уже сделана не как тест, а как валидатор — см.
`..\tools\`: `validate_mod.py`, `methodlint.py`, `upvaluecheck.py`,
`importcheck.py`. Они принимают путь к любому `.lua` и ничего не знают
про наши моды.

**Если валидатор уже делает проверку — не дублируй её здесь тестом.**
Ещё одна причина держать в проекте одно место правды.

## Чего здесь не будет

Тестов «просто чтобы было», и тестов, которые проходят всегда. Тест,
который не краснеет на сломанном коде, хуже отсутствия теста: он
создаёт уверенность, которой нет. Критерий пригодности — прогнать
`My_mods\overflow\tests\negative_overflow.py` и убедиться, что покраснело.
