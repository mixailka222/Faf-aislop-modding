# Стиль кода модов

Правила для нового кода. Старый код правится по ним только когда его всё равно меняют.

## Форматирование

- Отступ 4 пробела, без табов.
- Неравенство `~=`, а не `!=`.
- Строки в двойных кавычках. Одинарные допустимы там, где уже приняты в файле.
- Обход таблицы: `for k, v in t do`, если порядок не важен, и `for i, v in ipairs(t) do`, если важен.
- Длина таблицы: `table.getn(t)`. Оператора `#` в Lua игры нет.
- Строка не длиннее 120 символов.
- Файлы в UTF-8 без BOM.

Особенности Lua игры описаны в `DOCUMENTATION/knowledge/dialect.md`.

## Имена

| Что | Как | Пример |
|---|---|---|
| Функции, локальные и глобальные | `PascalCase` | `SelectNearest` |
| Методы классов | `PascalCase` | `GetPosition` |
| Переменные и параметры | `camelCase` | `nearestDistance` |
| Классы и импортированные модули | `PascalCase` | `Selection` |
| Приватные поля | `_camelCase` | `self._closeBtn` |
| Константы модуля | `UPPER_CASE` | `MAX_ROWS` |

Обычные слова вроде `name`, `count`, `index`, `value`, `line`, `type` можно использовать как имена переменных.

## Структура мода

Минимальный мод без зависимостей:

```text
ModName/
    mod_info.lua
    hook/lua/ui/game/gamemain.lua
    modules/main.lua
```

Мод на ReUI:

```text
ModName/
    mod_info.lua
    Main.lua
    Options.lua
```

`Main.lua` мода на ReUI начинается с версии и списка зависимостей:

```lua
Version = "1.0.0"

ReUI.Require
{
    "ReUI.Core >= 1.0.0",
    "ReUI.Actions >= 1.3.0",
}

function Main()
    ReUI.Core.OnPostCreateUI(function()
    end)
end
```

В модах на ReUI функции игры перехватываются через `ReUI.Core.Hook`, а не файлами в `hook/`, если мод не обязан работать без ReUI.

## Зависимости

- Если моду нужна библиотека интерфейса, берём ReUI.
- Если не нужна, зависимости нет.
- Зависимость указывается в `README.md` мода.

## Локальные копии глобальных функций

В коде, который работает часто, глобальные функции кэшируются локально в начале файла или функции:

```lua
local GetSelectedUnits = GetSelectedUnits
local TableInsert = table.insert
```

Вне такого кода это не требуется.

## Комментарии

- Язык английский.
- Комментарий объясняет то, что не видно из кода: поведение движка, ограничение, причину неочевидного решения.
- Описание функции для других частей кода пишется как `---` прямо над функцией. Причины и детали реализации пишутся обычным `--` внутри функции.
- Параметры и результаты описываются аннотациями `---@param` и `---@return` с типами.
- Нельзя ссылаться на локальные файлы, разделы документов, чат и задачи. Факт записывается прямо в комментарии.
- Нельзя писать историю изменений и номера версий файла. История есть в git.

```lua
--- Selects the unit closest to the mouse cursor.
---@param expression string category expression for UI_SelectByCategory
---@param excluded EntityCategory categories that must not stay selected
local function SelectNearest(expression, excluded)
    -- The selection is hidden so that other selection hooks do not react to it.
    ...
end
```

## Ошибки

- `pcall` не скрывает ошибку молча. Если вызов мог упасть, в ветке ошибки пишем `WARN` с контекстом: что вызывали и какие значения были.
- Защитный код не заменяет исправление причины. Если причина неизвестна, это прямо сказано в отчёте.
- Функция из файла игры вызывается через `import`, а не как глобальная. Вызов несуществующего глобального имени падает с ошибкой.

- `pcall(import, path)` не ловит ошибку компиляции модуля: `import` вернёт пустой модуль. Поле модуля проверяется через `rawget(Module, "Name")`, обычное чтение отсутствующего поля падает.
- В хуке точка входа мода читается через `rawget`, а работа мода идёт под `pcall`: ошибка в хуке ломает весь интерфейс.
- Функция, которая вызывается каждый кадр, и колбэк синхронизации сами оборачивают тело в `pcall`: игра этого не делает.
- `pcall` стоит вокруг работы между ожиданиями. `WaitSeconds` внутри `pcall` не работает.
- Колбэк `Selection.Hidden` не должен падать: ошибки ловятся внутри него. Временная смена выделения восстанавливается в каждой ветке.

```lua
local CommandMode = import("/lua/ui/game/commandmode.lua")

local ok, result = pcall(CommandMode.InCommandMode)
if not ok then
    WARN("MyMod: command mode check failed: " .. tostring(result))
end
```

## Частые ошибки

- Локальная функция объявляется выше первого использования. Иначе имя считается глобальным и вызов падает.
- Константы и состояние модуля лучше держать в таблицах: таблица считается как одно значение при пределе upvalue.
- Длина таблицы с произвольными ключами считается обходом: `table.getn` учитывает только ключи подряд от 1.
- Если значение не измерено, выводится `?`, а не 0.
- Ключи профиля пишутся без точек.
- Элементам, которые не должны реагировать на мышь, ставится `DisableHitTest`.

## Тесты

- Тесты мода лежат в `My_mods/<проект>/tests/`, имя файла `test_*.py`.
- Тест проверяет правило поведения, а не повторяет значение константы из кода. Вместо «рамка по умолчанию равна Vanilla» проверяем «значение по умолчанию есть в списке вариантов».
- Тест не меняет исходники мода. Если нужно проверить реакцию на поломку, поломка делается на временной копии.
- Заглушки функций игры объявляются до загрузки модуля. Ошибка в логе модуля считается провалом теста.
- Тест должен краснеть на сломанной копии кода, иначе он ничего не доказывает.

## `mod_info.lua`

Обязательные поля: `name`, `version`, `uid`, `description`, `ui_only`.

- `uid` уникален для каждой выпущенной версии мода, поэтому при выпуске он меняется.
- Для мода на ReUI добавляется тег `ReUI = "ИмяПапки=1.0.0"`: имя совпадает с папкой мода. Версия мода задаётся в `Main.lua`.
