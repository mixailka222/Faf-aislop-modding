# Проверка факта о FAF

Цель: не писать код по памяти или по аналогии. Факт считается проверенным, только если его можно открыть в источнике.

## Порядок

1. Найди факт в `DOCUMENTATION/knowledge/`. Если он там есть с источником, проверка не нужна.
2. Если папки `references/` нет, запусти `python DOCUMENTATION/tools/bootstrap.py`.
3. Ищи в источниках по порядку:
   - `references/fa/engine/` для функций и классов движка: это аннотации с типами;
   - `references/fa/lua/` для кода игры: это код, который получают игроки;
   - `references/ui-libs/mods/ReUI/` и `references/ui-libs/mods/UMT/` для API библиотек;
   - `references/lua-lang/` для особенностей Lua игры.
4. Если в источниках ничего нет, ищи сторонние базы и пиши, откуда взято.

Поиск из корня репозитория:

```bash
grep -rn "function InCommandMode" references/fa/lua references/fa/engine
```

## Что значит «проверено»

- Функция существует, если есть её объявление, а не только упоминание.
- Глобальная функция объявлена в `references/fa/engine/`. Функция в файле из `references/fa/lua/` доступна только через `import` этого файла.
- Отсутствие в поиске не доказывает, что функции нет: проверь другое написание и регистр.
- Поведение в игре нельзя подтвердить чтением кода, если код только похож на нужный. Тогда это наблюдение, которое надо проверить в игре.

## Запись факта

Новый общий факт добавляется в подходящий файл `DOCUMENTATION/knowledge/` в той же работе. Факт об одном моде идёт в `My_mods/<проект>/README.md`.

```markdown
### Короткое утверждение

Что важно знать. Без истории того, как это выяснилось.

Источник: fa:lua/ui/game/commandmode.lua#function InCommandMode
```

После `#` идёт текст, который есть в файле. Префиксы: `fa:`, `ui-libs:`, `lua-lang:`. Внешний источник указывается полной ссылкой `https://`.

Вместо источника допустимы:

```markdown
Наблюдение: условия опыта, что сделали и что увидели.
Не подтверждено: что нужно, чтобы проверить.
```

Если факт оказался неверным, исправь или удали его, а не дописывай рядом.

Проверь результат: `python DOCUMENTATION/tools/check.py --knowledge`, строка `база знаний` должна быть `[OK]`.
